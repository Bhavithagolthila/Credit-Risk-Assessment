A guide, not a verdict.

Credit Ledger is a learning project built around a calibrated XGBoost classifier. It estimates how likely a recorded loan default is, based on the details you enter.

The result is not a lending decision and does not prove anyone is creditworthy. Training data can carry historical bias, so never use it as the only basis for a real financial decision.
